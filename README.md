# Expense Tracking & Spending Analysis

## Project Overview

This project analyzes personal expense data to understand spending patterns, category-wise expenses, payment methods, daily spending, and budget performance.

The project was created using SQL and Microsoft Excel.

## Objectives

- Analyze total spending and transactions
- Analyze spending by category
- Compare necessary and unnecessary expenses
- Analyze daily spending
- Analyze payment methods and locations
- Compare budget with actual spending
- Identify highest and lowest expenses
- Create an Excel dashboard

## Tools Used

- SQL
- Microsoft Excel
- Excel Tables
- Excel Formulas
- Charts
- GitHub
